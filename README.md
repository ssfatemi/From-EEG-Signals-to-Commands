# From EEG Signals to Commands

**Supplementary Material for:**\
**From EEG Signals to Commands: A Review of Machine Learning Pipelines in Motor Imagery Brain-Computer Interfaces**

This repository contains supplementary resources for the review paper, providing a structured collection of **MI-BCI datasets** and **publicly available code repositories** relevant to machine-learning-based decoding of motor imagery EEG signals.

## Repository Contents

- **[Datasets](./Datasets/Readme.md)** — A curated list of publicly available EEG datasets commonly used in MI-BCI research, including BCI Competition datasets, PhysioNet EEG Motor Movement/Imagery, High-Gamma, BNCI, OpenBMI, Cho2017, and resources available through MOABB.
- **[Code](./Code/Readme.md)** — A collection of public implementations and software resources covering EEG preprocessing, spatial filtering, covariance/Riemannian methods, feature fusion, attention-based deep learning, lightweight MI-BCI models, and hardware-efficient implementations.

## Purpose

The repository is intended to support **reproducibility, methodological comparison, and further research** related to the machine-learning pipeline from EEG acquisition and preprocessing to feature extraction, classification, and command decoding in motor imagery brain-computer interfaces.
